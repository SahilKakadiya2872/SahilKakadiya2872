## About Me

I'm a **Master's student in Software Engineering** at Hochschule Heilbronn, Germany — focused on VR development and interactive 3D applications.

I build immersive environments using **Unity** and the **Meta XR Interaction Toolkit** — setting up interaction systems, solving cross-engine asset problems between Unreal and Unity, and testing everything on real hardware.

Before moving to Germany, I worked as a **UI/UX Designer**, which shaped how I think about interaction design in VR: usability first, then polish.

- 🎓 M.Sc. Software Engineering — Hochschule Heilbronn
- 🏅 Unity VR Development Certified — Unity Technologies
- 📍 Heilbronn, Germany
- 🔭 Currently: VR Development & Master's Thesis
